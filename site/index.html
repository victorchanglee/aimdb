Dataset

A machine-mined reference set of multireference (CASSCF-family) calculations, extracted from the open-access literature.

Each row is one compound + method result: CASSCF, RASSCF, CASPT2, RASPT2, NEVPT2, DMRG, or MRCI, on either a transition-metal complex or a metal-free organic molecule. Every stored value is copied verbatim from the paper — nothing is inferred or estimated — so each entry is traceable back to a specific statement in a specific publication. See CLAUDE.md in the repository for the exact extraction policy.

Raw data: database/literature.csv on GitHub.
