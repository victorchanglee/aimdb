Dataset

The dataset is comprised a set of multiconfigurational quantum chemistry calculations from available literature mined using large languange models (LLMs).

Field coverage

Empty is supposed to mean empty. The policy is that a blank cell means the paper did not state it, never a plausible default filled in by inference. But the extraction is LLM-mined, not hand-verified line by line, so some blanks may instead be fields the model missed rather than fields the paper omitted; corrections are welcome via the How to contribute form.

Some of the weak columns above are because the papers do not cover it, not because extraction missed anything. For example, many studies converge states individually rather than state-averaging over a stated number of roots, so nroots_per_mult has nothing to record.

The dataset and mining process is Open Source:

  • See CLAUDE.md in the repository for the exact extraction policy.
  • Raw data: database/aimdb.csv on GitHub.

How to contribute

AIMdb is a free, open source academic project. Any help or contribution is welcome. There are two ways to contribute: the form below, or a pull request on GitHub.

1. Pull request on GitHub

If you are comfortable with git, open a pull request against github.com/victorchanglee/aimdb. This suits larger batches — several compounds, or a whole paper's worth of entries — and lets the review happen against a diff. Add one row per compound to database/aimdb.csv, keeping the existing column order, and please include for every row: the DOI of the source paper, the active space (number of electrons and orbitals), the method and basis set, and a note saying where each value came from. Values must be stated by the paper — a field the paper does not give is left empty rather than estimated. The contribution guide in CLAUDE.md describes the columns and conventions in full.

2. Submission form

To contribute a single entry, fill in the fields below. Submitting opens a pre-filled email to the maintainer with your entry. Every submission goes into a separate review queue — nothing is added to the database automatically; the maintainer checks each entry before it is accepted. The same is true of pull requests: they are reviewed against the source paper before being merged.
